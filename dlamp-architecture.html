DLAMP.tw Architecture

Data-driven Limited Area Mesoscale Prediction — dual Swin-Transformer + DDPM forecast pipeline

Models

  • • PanguModel: Swin-Transformer, 29M params
  • • GlideUNet: ResUNet+Attention, 672M params
  • • Dual backbone: deterministic mean + stochastic convection
  • • Input: upper-air (Z,H,W,C) + surface (H,W,C)

Workflow

  • • train.py → Hydra configs + PyTorch Lightning
  • • predict.py → ONNX inference (CUDAExecutionProvider)
  • • Multi-step iterative forecasting with boundary swap
  • • Export to WRF-compatible NetCDF, matplotlib plots, GIFs

Data

  • • Sources: OPERA/ERA5, OPERA_E2S, CWA_RWRF NetCDF
  • • 4km resolution, 21 vertical levels for Taiwan region
  • • Z-score standardization per model version
  • • Env vars: DLAMP_EXP_CODE, DLAMP_DATA_SOURCE, DLAMP_DATA_PATH
