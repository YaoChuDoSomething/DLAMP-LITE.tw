# dlamp-monorepo-refactor

Label: wayfinder:map

## Destination

Merge **DLAMP.tw** (forecasting, `main/dlamp`) and **DLAMP.data** (data pipeline, `github/dlamp-data`) into a brand-new monorepo (new GitHub repo + new local dir, both git histories preserved) at a standard src-layout: everything importable under a single `src/dlamp/` namespace — legacy DLAMP.tw modules (`analysis/`, `inference/`, `visual/`, `src/{models,datasets,utils,managers,debug}`) folded in, and the data pipeline preserved as `dlamp.data.<component>` (core, tasks, registry, io, tools, definition). Top-level non-packaged data dirs (`config/`, `assets/`, `gallery/`, `export/`, `outputs/`); `train.py`/`predict.py` become console entry points. Docs follow `CONTEXT.md` + `docs/adr/` + `docs/{design,testing}`.

Reaching the end of this map = a **locked design/spec** living in the monorepo: the refactor design doc, the testing specification (including a regression strategy proving the refactor is behavior-preserving), and per-module test plans — such that execution sessions can perform the move without any further decisions.
