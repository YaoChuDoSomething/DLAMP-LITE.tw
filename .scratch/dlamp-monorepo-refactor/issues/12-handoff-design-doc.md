- **Map-done definition**: state explicitly when the map is complete (all decisions locked, design doc + testing docs written, frontier empty) and that execution then begins as a separate effort.
- Whether the design doc itself is written by this effort's sessions or is the execution team's first task.

Grill one decision at a time; the answer records the handoff contract that closes the map.
