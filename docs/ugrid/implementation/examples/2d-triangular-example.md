# 2D 三角形網格示例 (2D Triangular Mesh Example)

## 📖 概述

本示例演示如何使用 UGRID 表達一個**二維三角形非結構化網格（2D Triangular Unstructured Mesh）**——最廣泛應用於海洋和大氣數值模擬的網格類型。

**適用場景**：

- 海灣、河口、近岸海洋模型（如 FVCOM、Delft3D-FM）
- 地表水洪水模擬
- 大氣邊界層模擬
- 任何需要局部加密或複雜邊界的問題

在 2D 三角形網格中，基本元素為：

```text
           ○ Node 2
          /|
         / |
edge2   /  | edge1
       /   |
      /    |
     ○─────○
Node 0    Node 1
      edge0
```

每個**面（Face）= 三角形**，由 3 個節點定義。

## 🗺️ 示例：台灣北部海域三角形網格

以下示例模擬台灣北部海域（基隆港附近）的溫度和鹽度分布：

```text
    ○─────○─────○─────○   ← 近岸（水淺，網格密）
   /|\   /|\   /|\   /|
  / | \ / | \ / | \ / |
 ○  ○  ○  ○  ○  ○  ○  ○
  \ | / \ | / \ | / \ |
   \|/   \|/   \|/   \|/
    ○─────○─────○─────○   ← 遠海（水深，網格粗）
```

## 🐍 Python 讀取與視覺化

```python
"""讀取並視覺化 2D 三角形 UGRID 網格的示例。"""

import netCDF4 as nc
import numpy as np
import matplotlib.pyplot as plt
import matplotlib.tri as mtri

def plot_2d_triangular_mesh(filename: str, time_step: int = 0) -> None:
    """繪製 2D 三角形網格上的溫度分布。
    
    Args:
        filename: UGRID NetCDF 檔案路徑。
        time_step: 要視覺化的時步索引。
    """
    ds = nc.Dataset(filename)
    
    # 讀取座標
    node_lon = ds.variables['Mesh2_node_lon'][:]
    node_lat = ds.variables['Mesh2_node_lat'][:]
    face_nodes = ds.variables['Mesh2_face_nodes'][:] - \
                 int(ds.variables['Mesh2_face_nodes'].start_index)
    
    # 讀取海面溫度（σ = 0，表層）
    temperature = ds.variables['temperature'][time_step, -1, :]  # 最後一層 = 表層
    face_lon = ds.variables['Mesh2_face_lon'][:]
    face_lat = ds.variables['Mesh2_face_lat'][:]
    
    # 建立 matplotlib 的三角化物件
    triangulation = mtri.Triangulation(node_lon, node_lat, face_nodes)
    
    fig, axes = plt.subplots(1, 2, figsize=(14, 6))
    
    # 左：網格結構
    ax = axes[0]
    ax.triplot(triangulation, 'b-', linewidth=0.5, alpha=0.7)
    ax.scatter(node_lon, node_lat, c='blue', s=30, zorder=5, label='節點')
    ax.scatter(face_lon, face_lat, c='red', s=20, zorder=5,
               marker='^', label='面中心')
    ax.set_xlabel('經度')
    ax.set_ylabel('緯度')
    ax.set_title('三角形網格結構')
    ax.legend()
    ax.set_aspect('equal')
    
    # 右：溫度場（面中心插值到節點）
    ax = axes[1]
    # 將面資料插值到節點（簡單的鄰近平均）
    node_temp = np.zeros(len(node_lon))
    count = np.zeros(len(node_lon))
    for i, (n0, n1, n2) in enumerate(face_nodes):
        for n in [n0, n1, n2]:
            node_temp[n] += temperature[i]
            count[n] += 1
    node_temp = np.where(count > 0, node_temp / count, np.nan)
    
    tripcolor = ax.tripcolor(
        triangulation, node_temp,
        cmap='RdYlBu_r', vmin=18.0, vmax=22.0
    )
    plt.colorbar(tripcolor, ax=ax, label='溫度 (°C)')
    ax.triplot(triangulation, 'k-', linewidth=0.3, alpha=0.3)
    ax.set_xlabel('經度')
    ax.set_ylabel('緯度')
    ax.set_title('海面溫度分布')
    ax.set_aspect('equal')
    
    plt.tight_layout()
    plt.savefig('triangular_mesh_visualization.png', dpi=150, bbox_inches='tight')
    plt.show()
    
    ds.close()
```

## 🔍 常見問題

### Q1: 面-節點連線性的節點順序重要嗎？

是的。UGRID 建議使用**逆時針（Counter-Clockwise, CCW）**順序，因為許多數值方法（如有限體積法）依靠正確的方向性計算面法向量。但 UGRID 規範本身不強制此約束。

```text
// ✅ 逆時針（CCW）順序（建議）
Mesh2_face_nodes:
  0, 1, 3,    // ○──○ 逆時針

// ⚠️ 順時針（CW）順序（功能上允許，但不建議）
  3, 1, 0,
```

### Q2: 如何表達四邊形（混合三角形和四邊形）？

使用 `nMaxNodesPerFace` 維度和 `_FillValue`：

```cdl
// 混合網格示例
nMaxNodesPerFace = 4 ;  // 最多 4 個頂點

integer Mesh2_face_nodes(nMesh2_face, nMaxNodesPerFace) ;
  Mesh2_face_nodes:cf_role = "face_node_connectivity" ;
  Mesh2_face_nodes:_FillValue = -9999 ;  // 三角形的第 4 個頂點用 _FillValue

data:
  Mesh2_face_nodes =
    0, 1, 3, -9999,   // 三角形（第 4 位為 _FillValue）
    1, 2, 5, 4 ;      // 四邊形（4 個節點）
```
